# TennisLog public website

Static marketing, interactive browser prototype, support, privacy and terms.
Store name: TennisLog: Gear & Match Log (27 characters).
No native app source, credentials, signing artifacts or private keys belong here.

Source prototype was supplied by the user. The tennis court and icon artwork are original geometric SVG/CSS. No external fonts, analytics or advertising scripts are loaded.

The native iPhone app and this prototype are separately implemented. The iPhone app uses Apple subscriptions through RevenueCat and is preparing for App Store release. Purchases are unavailable on this website. Demo records are separate from native records.
