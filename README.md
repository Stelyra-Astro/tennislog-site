# TennisLog public website

Static marketing, interactive browser prototype, support, privacy and terms.
Store name: TennisLog: Gear & Match Log (27 characters).
No native app source, credentials, signing artifacts or private keys belong here.

Source prototype was supplied by the user. The tennis court and icon artwork are original geometric SVG/CSS. No external fonts, analytics or advertising scripts are loaded.

The native iPhone app and this browser demo are separately implemented. The current iPhone app stores personal records locally and supports default-on private iCloud sync plus separate Files backups. It uses Apple subscriptions through RevenueCat and is preparing for App Store release. Purchases and iCloud sync are unavailable on this website. Browser records and JSON backups are separate from native records and backups.
